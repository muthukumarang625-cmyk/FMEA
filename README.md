# Supply Chain Risk Prioritization (MCDM)

- fuzzy_topsis_risk.py: fuzzy TOPSIS in Python (numpy only) with RPN comparison, Spearman correlation, and weight sensitivity analysis.
  Run: python fuzzy_topsis_risk.py
- risk_prioritizer.html: standalone web tool (fuzzy TOPSIS + VIKOR). Open in any browser.

Sample ratings are made up. Replace them with your own expert survey data before reporting results.
